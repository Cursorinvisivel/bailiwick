# Pattern: GCP Naming Conventions — SUPERSEDED

> **Superseded by [`caf-naming-taxonomy.md`](caf-naming-taxonomy.md) (2026-06-24).**
> The former `{env}-{region}-{service}-{purpose}` format was replaced by the Azure
> CAF-based framework-wide taxonomy `{org}-{type}-{workload}-{env}-{region}-{instance}`.
> The old `{service}` token maps to the new `{type}` token; the env and region
> abbreviation tables carried over unchanged.

See `caf-naming-taxonomy.md` for the current guideline.
